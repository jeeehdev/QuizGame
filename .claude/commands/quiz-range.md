인자: $ARGUMENTS

`server/data/questions.json`에서 첫 번째 값(시작 번호)부터 두 번째 값(끝 번호)까지의 문제를 검토해 줘.

## 번호와 범위

- 번호는 `questions.json` 배열 순서를 1부터 센 것이다 (1~10 한국사, 11~20 과학, 21~30 지리, 31~40 예술과 문화)
- 시작 번호와 끝 번호를 모두 포함한다
- 다음 경우에는 검토하지 말고 사용법(`/quiz-range 11 20`)을 보여 준다
  - 시작 번호나 끝 번호가 비어 있거나 정수가 아닐 때
  - 1보다 작거나 전체 문제 수보다 클 때
  - 시작 번호가 끝 번호보다 클 때

## 확인할 것

### 1. 난이도
- 범위 안 문제의 쉬움·보통·어려움 개수와 비율
- 범위가 한 카테고리 10문제를 모두 포함하면, PRD 기준(카테고리마다 쉬움 4 · 보통 4 · 어려움 2)과 맞는지 확인한다
- 문제마다 붙은 난이도가 내용에 맞는지 판단한다. 중학교 교과서 수준의 기본 상식은 쉬움, 고등학교 교과서 수준이나 연도·인물을 정확히 알아야 하면 보통, 전문 지식이나 세부 사항을 묻거나 보기끼리 헷갈리기 쉬우면 어려움으로 본다. 맞지 않으면 ⚠️로 표시하고 알맞은 난이도를 제안한다

### 2. 정답 분포
- `answerIndex`(0~3)를 보기 번호 1~4로 바꿔 번호마다 몇 번 정답인지 센다
- 한 번호가 범위의 절반 이상이거나, 같은 번호가 3문제 이상 연달아 정답이면 ⚠️로 표시한다
- 참고: 서버가 출제할 때 보기를 섞으므로, 플레이어에게 보이는 정답 위치는 이 분포와 다르다. 이 분포는 파일 검수표를 볼 때 편향이 없는지 확인하는 용도다

## 출력 형식

1. 문제 표. 열: 번호 | id | 카테고리 | 난이도 | 문제(앞부분) | 정답 번호 | 난이도 판정
2. 난이도 요약표: 쉬움 / 보통 / 어려움 개수와 비율. 카테고리 10문제를 모두 포함했으면 PRD 기준과 비교한 결과
3. 정답 분포표: 보기 1 / 2 / 3 / 4가 각각 몇 번 정답인지, 그리고 ⚠️ 해당 여부
4. 한 줄 요약: "N번~M번 · K문제 · 난이도 ⚠️ a건 · 정답 분포 ⚠️ b건"
5. 파일은 수정하지 않는다. 고칠 점이 있으면 반영할지 물어본다
