`/teacher-mode ... save`로 저장한 보고서를 CSV나 PDF로 내보내 줘. 공통 규칙은 `docs/teacher-mode.md`를 따른다.

인자: $ARGUMENTS
- `csv`, `pdf`, `both` 중 하나가 형식이다 (기본 `both`)
- `.md`로 끝나는 값은 보고서 파일 경로다. 없으면 `teacher/reports/`에서 파일 이름이 가장 늦은(가장 최근) `.md`를 쓴다
- 그 밖의 값이면 시작하지 말고 사용법(`/export-report pdf`, `/export-report csv teacher/reports/2026-10-14-0350-all.md`)을 보여 준다

## 1. 준비

- 보고서 파일이 없거나 `teacher/reports/`에 `.md`가 하나도 없으면 `/teacher-mode <기간> save`로 먼저 저장하라고 안내하고 멈춘다
- 보고서가 `# <반 이름> 퀴즈 성적 보고서`로 시작하는지 확인한다. 아니면 선생님 모드 보고서가 아니라고 알리고 멈춘다
- `teacher/`가 `.gitignore`에 있는지 확인한다. 없으면 학생 이름이 든 파일이 저장소에 올라갈 수 있으므로 멈추고 알린다
- 결과 파일은 보고서와 같은 폴더에 같은 이름으로 확장자만 바꿔 만든다 (`2026-10-14-0350-all.md` → `2026-10-14-0350-all.csv`, `.pdf`). 같은 이름이 있으면 덮어쓰지 않고 뒤에 `-2`, `-3`을 붙인다

## 2. CSV

보고서의 `## 반 성적표` 섹션에 있는 학생별 성적표를 CSV로 만든다.

- 열은 보고서 표의 열을 그대로 쓰고, 맨 앞에 `반`, `기간` 열을 붙인다 (보고서 둘째 줄의 기간)
- 이름 칸의 ⚠️·⭐ 표시는 이름에서 떼어 `표시` 열로 옮기고 글자로 쓴다: ⚠️ → `주의`, ⭐ → `우수`. 빠른 기록(⏱️)은 "빠른 기록" 열 값 그대로 둔다
- 굵게(`**`) 같은 Markdown 기호는 지운다. 미응시 학생 줄도 그대로 넣는다
- 숫자는 숫자로, 정답률은 `%`를 뺀 숫자로 쓴다 (`73%` → `73`). 열 이름에 단위를 붙인다 (`한국사(%)`)
- Excel이 다른 값으로 바꾸지 않게 한다
  - `반 안 순위`의 `2/3`은 날짜(2월 3일)로 바뀌므로 `순위`(2)와 `응시 학생 수`(3) 두 열로 나눈다. `-`(미응시)는 두 열 모두 빈 칸
  - `평균 소요 시간`의 `0:45`는 시각으로 바뀌므로 초로 바꿔 `평균 소요 시간(초)`(45)로 쓴다
  - 수학 기호 `−`(U+2212)는 숫자로 읽히지 않으므로 `-`로 바꾼다 (`−13` → `-13`, `+17` → `17`)
- 형식: UTF-8 **BOM 포함**(Excel에서 한글이 깨지지 않게), 쉼표 구분, 줄바꿈 CRLF. 쉼표·따옴표·줄바꿈이 든 값은 큰따옴표로 감싸고 안의 큰따옴표는 두 번 쓴다
- 보고서에 `## 약한 카테고리와 많이 틀린 문제` 섹션의 문제 표가 있으면 `<이름>-questions.csv`로 따로 만든다 (같은 규칙)

**검증**: 만든 CSV를 다시 읽어 행 수가 보고서 표의 학생 수(문제 표는 문제 수)와 같고, 모든 행의 열 수가 머리글과 같은지 확인한다

## 3. PDF

보고서 전체를 PDF로 만든다.

1. **HTML로 바꾸기**: 일회용 변환 스크립트를 scratchpad에 만들어 보고서 Markdown을 HTML 한 파일로 바꾼다. 중간 HTML도 scratchpad에 둔다
   - 제목(`#`~`###`), 표, 목록, 굵게, 인라인 코드, 문단, 구분선을 바꾼다. 보고서에 들어갈 일이 없는 다른 문법은 다루지 않아도 된다
   - 외부 파일·폰트·스크립트를 쓰지 않는다. 글꼴은 `"Malgun Gothic", "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`
   - 인쇄용 CSS: A4, 여백 15mm, 표에 테두리, 머리글 행 배경색, 표 줄이 페이지 사이에서 잘리지 않게(`break-inside: avoid`), 제목 바로 뒤에서 페이지가 나뉘지 않게
   - 이모지(⚠️⭐⏱️📈📉➡️)는 그대로 둔다
2. **PDF로 인쇄**: 설치된 Chrome 또는 Edge를 헤드리스로 실행한다
   - Windows: `C:\Program Files\Google\Chrome\Application\chrome.exe`, 없으면 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
   - `--headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf=<결과 PDF> <HTML 파일의 file:/// URL>`
   - 둘 다 없으면 PDF는 만들지 않고 이유를 알린다 (CSV는 계속 만든다)

**검증**: PDF 파일이 있고 크기가 0보다 크며 `%PDF`로 시작하는지 확인한다. 첫 페이지를 읽어(Read 도구로 PDF 열기) 제목과 성적표가 보이고 한글이 깨지지 않았는지 확인한다. PDF를 열 수 없으면(예: poppler 없음) 같은 브라우저로 중간 HTML을 캡처해(`--headless=new --hide-scrollbars --window-size=900,1500 --screenshot=<scratchpad의 PNG>`) 그 이미지로 확인한다. 페이지 수는 PDF 안의 `/Type /Page` 개수로 센다

## 4. 보고

- 만든 파일 경로와 크기, CSV 행 수, PDF 페이지 수
- 검증 결과. 실패한 것이 있으면 오류 원문
- 결과 파일에도 학생 이름이 들어 있으므로 저장소나 외부로 공유할 때 주의하라는 한 줄

## 하지 않는 것

- 보고서 원본(.md), 명단, DB는 바꾸지 않는다. 새 패키지를 설치하지 않는다
- `teacher/reports/` 밖에 결과 파일을 만들지 않는다 (중간 HTML·스크립트는 scratchpad)
