퀴즈 게임 DB에 저장된 기록으로 통계를 보여 줘.

기간: $ARGUMENTS
- 비어 있거나 `all`이면 전체, `today`면 오늘(로컬 시간), `7d`·`30d`처럼 숫자+d면 최근 N일
- 그 밖의 값이면 계산하지 말고 쓸 수 있는 값을 보여 준다

## DB 읽는 방법

- DB 경로는 환경 변수 `DB_PATH`, 없으면 `server/data/quiz.sqlite` (`server/src/config.ts`와 같음)
- **읽기 전용으로만 연다.** `better-sqlite3`로 `new Database(path, { readonly: true, fileMustExist: true })`처럼 열고, 일회용 스크립트는 scratchpad에 만들어 `node`로 실행한다. `openDb`는 테이블을 만들기 때문에 쓰지 않는다. INSERT·UPDATE·DELETE는 하지 않는다
- DB 파일이 없거나 기록이 0건이면 "아직 저장된 기록이 없습니다"라고 알리고 끝낸다
- 테이블 구조는 `server/src/db.ts`를 따른다
  - `scores`: 40문제를 끝까지 푼 게임만. `score`(0~400), `correct_by_category`(JSON: 카테고리별 맞힌 수), `duration_sec`, `played_at`(ISO 문자열, UTC)
  - `games`: 최근 24시간 안에 시작한 게임(진행 중·중단·완료). `plan`, `answers`(JSON: questionId, correct), `finished`, `started_at`(ms)

## 보여 줄 통계

### 1. 전체 요약 (`scores`, 기간 적용)
- 완료한 게임 수, 서로 다른 닉네임 수
- 점수: 평균, 중앙값, 최고, 최저, 만점(400점) 횟수
- 소요 시간: 평균, 중앙값, 가장 빠른 기록 (분:초)
- 점수 분포: 0~99 / 100~199 / 200~299 / 300~399 / 400 구간별 게임 수

### 2. 카테고리별 정답률 (`correct_by_category`, 기간 적용)
- 한국사·과학·지리·예술과 문화 각각 평균 맞힌 수(10문제 중)와 정답률
- 가장 어려운 카테고리와 가장 쉬운 카테고리

### 3. 날짜별 플레이 수 (`scores`, 기간 적용)
- 날짜(로컬 시간)별 완료 게임 수. 날짜가 많으면 최근 14일만

### 4. 최근 24시간 문제별 정답률 (`games`)
- `games`는 24시간이 지나면 지워지므로 기간 인자와 상관없이 최근 24시간만 계산한다고 밝힌다
- 시작한 게임 수, 완료 수, 중간에 나간 게임 수(완료율)
- 답이 5번 이상 모인 문제만 정답률을 계산해, 정답률이 낮은 문제 5개와 높은 문제 5개를 id와 문제 앞부분과 함께 보여 준다
- 정답률이 매우 낮거나(20% 미만) 매우 높은(95% 초과) 문제는 난이도 조정 후보로 표시하고, 그 문제의 현재 난이도를 함께 적는다

## 출력 형식

- 위 4개 섹션을 표로 보여 주고, 맨 위에 기간과 DB 경로를 적는다
- 마지막에 눈에 띄는 점을 2~3줄로 정리한다 (예: 지리 정답률이 다른 카테고리보다 20%p 낮음)
- 파일과 DB는 수정하지 않는다. 기록 삭제가 필요하면 `/quiz-leaderboard`를, 문제 난이도 조정이 필요하면 `/quiz-range`·`/quiz-swap`을 안내한다
